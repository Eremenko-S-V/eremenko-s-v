# Резюме — Еременко Станислав

Одностраничное резюме (HTML + CSS). Файл `resume-eremenko-stanislav.txt` — версия для скачивания и откликов.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой сервер:

```bash
npx --yes serve .
```

## Публикация

Сайт публикуется через GitHub Pages из ветки `master`.
