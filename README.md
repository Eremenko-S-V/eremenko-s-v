# Резюме — Еременко Станислав

Одностраничное резюме (HTML + CSS). Файл `resume-eremenko-stanislav.txt` — версия для скачивания и откликов.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой сервер:

```bash
npx --yes serve .
```

### Адрес `https://eremenko-s-v.github.io`

Такой URL даёт только **личный сайт GitHub** с именем аккаунта `eremenko-s-v`:

1. [Переименовать аккаунт](https://github.com/settings/admin) `natas-sait` → `eremenko-s-v` (логин, похоже, свободен).
2. Создать репозиторий `eremenko-s-v.github.io` и перенести сюда файлы сайта — тогда адрес будет **https://eremenko-s-v.github.io/** без `/eremenko-s-v` в пути.

Свой домен вида `eremenko-s-v.ru` — через файл `CNAME` в репозитории и DNS у регистратора.
